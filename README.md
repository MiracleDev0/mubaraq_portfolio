# Gbadamosi Mubaraq — Portfolio

Personal portfolio site for Gbadamosi Mubaraq, .NET Backend Developer.

Built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/data/portfolio.ts` — all site content (profile, skills, experience, projects, contact)
- `src/components/` — page sections (Hero, About, Skills, Experience, Projects, Contact, Footer)
- `public/resume/` — downloadable CV
